# Security Policy

If you discover a security vulnerability in this project (such as authentication bypass, injection, sensitive information disclosure, etc.), **please do not report it via a public Issue** — public disclosure could be exploited to attack users running active instances.

## How to Report

Send an email to **anonymous@example.com**, preferably including:

- Vulnerability type (Authentication Bypass / Injection / Sensitive Information Disclosure / Other)
- Reproduction steps and impact assessment
- Your contact information (for follow-up and acknowledgment)

## Our Commitment

- Acknowledge receipt within **72 hours**
- Release fixes in an upcoming version and **publicly credit** the reporter in the release notes (unless you prefer to remain anonymous)

## Scope

Security reports are welcome for all publicly released versions of this project (both Community Edition and Pro Edition).
