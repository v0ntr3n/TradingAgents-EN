## Writing Style Guidelines

1. **Every lesson must start with "What problem this lesson solves"** in a single sentence.
2. **Every lesson must end with "Hands-On Practice"** so the user runs a real workflow in the system.
3. **Screenshot references**: use `images/lesson-XX/XX-xxx.png` path.
4. **Code examples**: Python/JavaScript snippets must be directly runnable.
5. **Avoid fluff**: minimize abstract theory, focus on "where to click in the system".
6. **Keep practical terminology**: retain clear educational terms where appropriate.
7. **Cross-lesson links**: use relative paths `[lesson-05](file:///.../lesson-05-xxx.md)`.
